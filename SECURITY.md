# Security policy

## Reporting a vulnerability

Please do not report security vulnerabilities in public issues or discussions. Use GitHub's **Report a vulnerability** option on the repository's **Security** tab to send a private report. Include steps to reproduce the issue and its potential impact, but do not include real member data.

If private vulnerability reporting is unavailable, contact the repository maintainer through GitHub and ask for a private channel before sharing technical details.

## Scope

The app is designed to process selected CSV files locally in the browser. Reports about data leaving the browser, unsafe CSV downloads, or cross-site scripting are especially important.
